# Math Problem Studio

A simple local app for generating math worksheets with editable behavior and design.

## Run

Open `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/index.html` in a browser.

No install/build step is needed.

## What You Can Change

1. Problem behavior (count, ranges, operations, negatives, decimals): edit controls in `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/index.html` and logic in `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/app.js`.
2. How questions are generated: edit `createProblem()` in `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/app.js`.
3. Visual design: edit CSS variables in `:root` inside `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/styles.css`.

## Key Files

- `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/index.html`: UI layout and controls
- `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/app.js`: generator logic, settings persistence, events
- `/Users/piotrkulikowski/Documents/New project/apka zadania/untitled folder1/styles.css`: theme and responsive layout

## Notes

- Settings are saved in browser local storage.
- "Show Answers" toggles answer visibility without changing problem rules.
